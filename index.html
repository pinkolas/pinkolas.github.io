🚀 Getting Started

Follow these simple steps to get virtuallyView running on your Windows PC. It should take less than 10 minutes.

1 Download the application

Visit this link to download the application: https://github.com/pinkolas/virtuallyView. This is the official download page. Look for the green "Code" button and select "Download ZIP" to get the files.

2 Extract the files

Once the download finishes, find the ZIP file in your "Downloads" folder. Right-click on it and select "Extract All". Choose a simple location like your Desktop or C:\virtuallyView. This will create a folder with all the necessary files.

3 Start the application

Open the extracted folder. Look for a file named virtuallyView.exe or start-virtuallyView.bat. Double-click it to start. Your web browser will automatically open, showing the virtuallyView dashboard.

4 Add your media sources

On your first launch, you'll see a setup wizard. Follow these steps:

  • Connect to your existing Radarr, Sonarr, Lidarr accounts (or create them later)
  • Add your qBittorrent download client
  • Set your media folder locations
  • Enable optional AI features for smart requests

Don't worry if this seems complex - the wizard has helpful explanations for each step.

5 Start streaming!

Once setup is complete, you'll land on your personal media home page. Browse your library, search for new titles, and click play. Your content streams instantly in your browser. Use the cast icon to send videos to your Chromecast-connected TV.

💡 Pro Tips for New Users

🔒 Run it locally: For security, keep virtuallyView on your home network. It's private and works perfectly without exposing it to the internet.

  • 📺 Optimize casting: Ensure your TV and computer are on the same Wi-Fi network for seamless Chromecast streaming.
  • 🎵 Music playback: Use the "Now Playing" bar at the bottom of the screen to control music while browsing other sections.
  • 🤖 Ask the AI: Click the sparkle icon in the search bar and type "Show me action movies from 2024" - the AI will find them instantly.
  • 📡 Live TV: Add IPTV channels through settings to watch live news and sports.

🛠️ Troubleshooting

If something isn't working, try these common fixes:

  • Can't start the app? Make sure you've extracted all files completely. Run as administrator by right-clicking the .exe file.
  • No streaming? Check that your media files are in the folders you specified during setup.
  • Chromecast not working? Restart both your computer and TV. Check network connections.
  • Forgot your settings? Delete the "config" folder in the installation directory to reset to defaults (your media stays safe).
